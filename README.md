🎀 Dream Closet — Smart Wardrobe & Outfit Recommendation System

Dream Closet is a full-stack fashion management platform designed to help users organize their personal wardrobe and discover stylish outfit combinations based on occasions, colors, and style compatibility.

The application allows users to digitally archive their clothing collection by uploading wardrobe items with details such as category, color, season, pattern, and occasions. Using a custom recommendation engine, the system analyzes available clothing items and generates the best outfit combinations for different events.

🧠 Recommendation Logic

The recommendation system uses a custom scoring algorithm:

Outfit Score =
Occasion Compatibility (40%)
+
Color Matching (30%)
+
Style Compatibility (30%)

The system evaluates multiple possible combinations and ranks them to provide the most suitable outfit suggestions.
